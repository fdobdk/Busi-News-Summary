# AI Folder

All AI-facing project assets are centralized here:

- `prompts/`: Prompt templates used by `scoring.py` and `rewrite.py`
- `architecture.mermaid`: Architecture map for fast context restore
- `workflow.md`: Collaboration conventions for AI-assisted development
- `tasks.md`: Structured task definitions for ongoing work
- `status.md`: Current progress, blockers, and next actions

When prompting in Cursor, reference these files first to quickly restore context.
